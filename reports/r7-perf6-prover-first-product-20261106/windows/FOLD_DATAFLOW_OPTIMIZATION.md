# C2 fold/input dataflow candidate

Existing first-round Polynomial and Fold independently traverse three std::function factors. Product knows the actual backing stores: equality weights of length width and one interleaved child vector of length 2*width. Each phase reads 3*width factor elements; together they invoke 6*width callbacks. Later rounds already fold three contiguous vectors in place and resize down without growing capacity. Merely rewriting that loop would not establish a cost reduction.

The proposed C2 passes borrowed, checked Product input references into the existing reduction. First-round specialized polynomial reads equality[2j,2j+1] and child[4j,4j+2,4j+1,4j+3] directly. After the unchanged FS challenge, the first fold uses those same backing arrays with no std::function or repeated vector::at calls. Remaining rounds retain existing folded storage/arithmetic. It adds no full-domain cache, no extra witness copy, and no new Verifier arithmetic. References expire before the caller clears factor closures and frees the tree level. An explicit Prover-only option controls selection.

The expected saving is removal of actual indirect calls and repeated bound checks, not a claimed reduction in all compulsory element reads. Both phases must still read inputs because the challenge is unavailable until after coefficients are committed. Caching a second full-domain representation was rejected before implementation: it increases peak storage from folded 3*width/2 to 3*width and is inconsistent with the <=1.05 RSS goal. Challenges never permit cross-layer equality-weight reuse.

The implemented fold also interleaves left/right child access in one traversal rather than two full strided child passes. This improves same-line reuse by construction; hardware cache-miss/DRAM traffic was NOT_MEASURED. Across Product layers of n=2^23, the analytical first-round callback reduction is 6*(n-2)=50,331,636. C2_DATAFLOW_RESULT.json compares A2+B2 and A2+B2+C2 in the same executable, separately from formal bundle acceptance. Later-round in-place buffer capacity is unchanged.

Independent hand-derived test: equality [2,3,5,7], child [11,13,17,19,23,29,31,37] gives coefficients [3621,3845,1368,164] and challenge-3 folded vectors [[5,11],[29,47],[31,53]]. Additional tests must cover zeros/negative Fr values, domain/shape rejection, generic equality and the complete FS/negative-test suite. C2 formal experiment is the explicitly labeled cumulative A2+B2+C2 bundle versus generic baseline; an isolated A2+B2 versus A2+B2+C2 diagnostic measures the local effect separately.

Executed implementation, test and performance status are recorded in C2_BUILD_RESULT.json/C2_VALIDATION.json/C2_AB_RESULT.json when present. This document alone is a design, not an acceptance claim.
