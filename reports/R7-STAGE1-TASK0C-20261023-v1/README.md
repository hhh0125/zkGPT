# R7 Stage1 Task0-C research artifact

This directory is an isolated interactive research prototype for committed Sumcheck and toy GKR. It is not a production NIZK and does not change R6 or historical R7 evidence.

Run from `research_only/`:

```text
python3 -B run_all.py
python3 -B measure.py
```

Hard research bounds: N≤1024, degree 2/3, H-PC K≤4, at most two toy GKR layers, width≤8, CPU≤120 seconds/process, address space≤512 MiB, JSON wire≤2 MiB. Trusted verifier receipts are interactive state and are excluded from proof wire.

The six required deliverables are under `delivery/`. Raw RED/GREEN/debug/resource logs are under `logs/`; primary papers and review log are under `literature/`; SHA/archive/restore evidence is under `evidence/` and the stage root.

The Python harness returns verifier challenge state from `prove_*` for single-process replay. It is valid only when the caller retains state generated by an honest verifier. Python type checks do not authenticate provenance; an external verifier-owned session API is required before any adversarial executable prototype.
