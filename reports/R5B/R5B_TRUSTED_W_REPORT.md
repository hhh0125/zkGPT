# Operator-trusted W binding

Implemented trust mode: OPERATOR-TRUSTED engineering model. Publisher-certified=false; approved numerical profile=false. Fixed hosted revision/checkpoint and the 120-file reconstruction evidence are reused rather than retraced. Model manifest: engineering-model-manifest-v1.txt, SHA `432ff04e367269c533f8f007d13d1975be8e8ccc246332899ce1c884dd0cbb99`. Anchor: operator-trust-v2.anchor, independently pinned SHA `cd339d42738ef8ffd2bce5853d0bbbbae7a32c9e80332dafe93de5e93e0c25aa`. The same anchor bytes/pin were copied to Windows and independently SHA-checked before proof generation.

`r5b_model_preprocess PARAMETER_DIR MANIFEST NEW_ANCHOR` verifies every one of the 120 parameter SHA entries and the exporter bytes, strictly parses FC/LN headers and sizes, constructs the verifier-owned oneblock padded W layout, and commits using the unchanged deterministic balanced-Hyrax-IPA-nonhiding-v1 PC. It records the profile canonical hash, circuit fingerprint, exact W PC identity/rows, model id derived from the pinned manifest, and manifest hash. There is no randomized W commitment that is merely asserted to follow from a file hash. The old GKR/master commitment and PC security assumptions are not changed.

`r5b_model_verify STATEMENT PROOF --trusted-anchor FILE --anchor-sha256 INDEPENDENT_HEX --model-manifest FILE` requires an explicit independently selected pin/configuration. It checks anchor hash before parsing, canonical anchor bytes, profile/hash, full manifest hash/format/table, circuit/layout/PC shape and model id; then compares the statement W to the anchor W. Only after that does it verify existing GKR/Lasso/common-input proofs. This is no longer `approved_w=statement.W`. The caller must protect the independent config; choosing a different trusted config is an operator trust decision, not publisher certification.

Oneblock W has 12 parameter regions, actual 13,645,824 scalars and padded 16,777,216. Only block0's ten parameter files affect this proof; remaining checkpoint files are manifest-pinned for model identity, not falsely counted as evaluated full12. Real independent preprocessing was compared with every production witness W scalar: 3,530,507 negative, 6,593,921 zero, and 3,131,392 padded tail scalars checked zero. Deterministic PC matched the already separately generated anchor. The mapping parser tests also cover signed-int32 extremes, output-major/padded FC, LN gamma/beta halves, region order, exact byte lengths, changed SHA, wrong header, truncation and extra trailing bytes; the small parser test passed with ASan+UBSan.

Local anchor tests accept the selected anchor and reject absent pin, wrong pin, W substitution, wrong model id, wrong profile, wrong manifest and noncanonical anchor bytes. Full serialized proof/statement substitutions and empty-directory independent acceptance are separate required acceptance evidence; see the final test report, not an assumption from these local tests. Official publisher certification and original-float parameter provenance remain unclaimed.
