# Witness / verifier consistency

The existing layered circuit is rebuilt by the independent verifier using its own fixed R5B flag and shape. Its fingerprint, zero suffixes, source maps and dimensions are compared with the statement. The verifier-owned query adapter reconstructs every span, affine bias, PC shape, Range bit width, Exp profile and public constant/padding coordinate, then compares the complete serialized query statement. All numeric advice remains in the original master. GKR terminal claims, lookup child values, X/Y/W, constants and tails enter the existing bridge plus unified mapped-input proof.

All newly allocated master slots are explicitly cleared before use; constants are separately bound to 1 and reserved slots to 0. LN output/centered padding is bound zero. Inactive LN output remainder/complement slots are range-bounded, initialized zero and have no active numerical consumer; canonical uniqueness of those unused slots is not claimed. Master/child zero tails use the retained mapped-input/lookup constraints. Independent verification never loads model parameter files or obtains W approval from the statement. It loads its separately selected anchor, verifies the independent pin and manifest/profile/circuit identity, then compares the actual W child against that anchor.

The new all-zero equality layers use the existing GKR zero-output machinery. Unary-only layers disable phase two; binary layers retain it. No parallel proof protocol is introduced. Genuine newly generated normal/hostile proof outcomes and actual serialized mutations are recorded in R5B_TEST_REPORT.md and raw runs JSON. Final independent normal acceptance and semantic negative rejections are complete; exact results and artifact hashes are retained in the final test report and evidence JSON.


Final independently accepted circuit has 51 authenticated input terminals. FC round additionally retains p*(p+bias-A)=0 to expose both existing FC parent points; this is redundant with A=p+bias and changes no target number. A real inconsistent lookup child was re-proved with valid local subproofs and rejected by the independent common-input verifier. Full serialized attacks reject altered Exp addressing/memory/commitments/profile, derived maps, missing Range, W, parent commitment, public Y/padding, candidate context, widened rounding endpoint domain, remainder commitment and LN positivity view. Boundary unit fixtures and serialized-binding attacks are distinct evidence; no separate full-model proof per half-tie is claimed.
