# Protocol compatibility argument

This is an ownership optimization, not a protocol fork. Unchanged source hashes cover protocol.cpp, sumcheck.cpp, pc.cpp, memory/range/exp.cpp, all GKR code, Fiat-Shamir code, wire encoders, numericalProfile and model mapping. The diff manifest lists every9changed source file; no hidden global commitment layout change.

1. For each validated mapped child, gatherInput formerly builds a padded zero vector and fills ordered spans with w[offset+z]+bias. The new check visits exactly the same ordered spans (including repeated/overlapping/bias spans), checks the same field values, then explicitly checks every remaining padded element zero. Size and source coverage validation are unchanged. Invalid witnesses are still rejected; no mathematical constraint is deleted.
2. The initial two Sumcheck factors are exactly [kernel,witness]. Moving a std::vector transfers ownership/capacity, preserving every field element and index. The sole working witness copy has the same values as the former copies. The existing proveSumcheck implementation, degree2 expression v[0]*v[1], index/fold order, round messages, labels and challenge calls are untouched. Induct on rounds: equal input factors and FS state imply equal polynomial messages, equal challenge, equal next folded factors and state; hence identical endpoint and proof. Only unreachable duplicate storage is removed, and factor capacities now die before final master opening.
3. Direct validation and allocation ownership add no transcript calls. Commitment generators, row/column layouts, actual/padded lengths, W/X/Y, table/tail identity, local Lasso order, GKR claims, bridge and common input bindings are untouched. Memory plan numeric values are not transcript inputs. Metadata additions only expose resource estimates.
4. planLookupBatch takes an optional maximum checked-input domain so kernel weights are accounted for, without changing what prove/verify computes. Standalone lookup defaults0(no checked claims); modelResources supplies max of real nonmaster layer input-port bits, exactly the fields used in gkr_verifier.cpp's authenticated claims, including second FC points. Malformed resource domains fail; proof domains are not widened.

Evidence: allocation tests pin original transcript digests at2^16/18/20, real mapping/boundary/malicious tests and independent checks remain green; full oneblock serialized statement/proof are byte-identical to the frozen original independently accepted artifacts; current independent verifier ACCEPTs them; full12 realbuilder compares every original layout/query/coordinate field. These tests corroborate the code-level equivalence argument, rather than replacing it. No full12proof or security theorem is claimed.
