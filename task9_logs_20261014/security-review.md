## Other quantization relations: bounded source inferences

These are pre-existing follow-up risks outside the exp-table fix, not demonstrated independent-verifier attacks. They prevent a claim of full exact quantized inference correctness without further work.

1. LayerNorm zero denominator is not cryptographically excluded. The honest producer enforces sigma>0 (neuralNetwork.cpp:948-950), but Range only requires sigma in an unsigned 64-bit interval including zero (1017-1020). For a constant real input row, choose sum=n*x and a_j=n*x_j-sum=0, B=1. The gate equations allow sigma=0 and delta1=(0+0+1-1)*(1-0+0)=0 (1067-1075,1175-1180), all within registered bounds. The y rounding terms then both equal 1, independent of every y_j, because all y and bias terms are multiplied by sigma and the centered input is zero (1134-1163). Set stored term1=term2=1 and delta2=1; layer3 product checks pass (1244-1245). Thus the local polynomial relation permits arbitrary in-range y for this conditional input, despite the honest producer rejecting sigma=0. No inverse/nonzero sigma constraint was located. Recommend explicit sigma>=1 (e.g. constrained sigma-1 or a proved inverse), strict sqrt interval constraints, and constant-input adversarial fixtures.

2. roundLayer proves a closed nearest-integer interval rather than std::round's exact half-away-from-zero rule. Producer uses round() (1603), but unsigned slacks permit zero (1611-1638); gate equalities preserve both endpoints (1673-1694). Local example c=1,m=-1,affine_p=1 has scaled input 0.5: q=0 gives (term1,term2)=(4,0), q=1 gives (0,4), and delta=0 for either. Both satisfy local Range/GKR equations, while the producer selects q=1. Recommend normatively specify and prove signed half-tie handling, then test positive and negative exact ties with recomputed witnesses.

3. GeLU branch threshold has an overlapping permitted selector boundary. Producer chooses t=1 iff C7*abs<=C6 (1315-1322). The proved d2=t+(1-2*t)*(C7*abs-C6) and unsigned Range allow t=0 AND t=1 at equality; t=1 also permits C7*abs=C6+1 (1330,1376-1379,1427-1434). Unlike a harmless branch tie, the polynomial pieces need not coincide. A source-algebra example using current coefficient inputs ea=eb=ec=ed=-8,ca=48,cb=217,cc=252,cd=615, and valid scale parameters ex=ey=-8,cx=cy=1 gives C6=615,C7=1,C5=2^24. At qx=abs=615, producer t=1 yields rounded y=606, whereas alternate t=0,d2=0 yields y=615. For the alternate branch, term1=term2=2^24+1 and delta3=(2^24+1)^2, fitting registered bounds and satisfying the local polynomial equations. This is an algebraic counterexample for these parameters, not evidence that production scale/input reach this boundary or that a full malicious artifact has been accepted. Recommend disjoint proved selector inequalities matching the producer and a boundary adversarial test for actual deployment scales.

GeLU and LayerNorm additionally use +1-expanded rounding slacks and unsigned ranges, while producers require positive slacks; inspect those endpoint semantics when defining exact rounding. These modules do contain polynomial mapping constraints, so it would be inaccurate to describe them generically as range-only lookups. The concerns are specific missing strictness/tie/nonzero conditions.
